# HabitFlow - Habit Tracking System

## Project Description
**HabitFlow** is a responsive web application designed for managing and tracking daily habits. The primary goal of the system is to enable users to:
* Create personalized habits.
* Track daily performance.
* Set customized timers.
* Manage and filter habits efficiently.
* Visualize progress clearly.

The system was designed with a focus on intuitive user experience (UX), clear navigation, and a clean design that encourages persistence and daily use.

## Website Structure
The site consists of five main pages:
* **Home** – Introduction and guidance.
* **About** – Information about the system and the team.
* **My Habit** – The core of the system for habit management.
* **Dashboard** – Data visualization and progress tracking.
* **Connect** – Contact page.

The site is fully responsive and optimized for both **Desktop** and **Mobile** views.

## Technologies
The system was developed entirely as a Frontend project using:
* **HTML5** – Semantic and accessible hierarchical structure.
* **CSS** – Responsive design using Grid/Flexbox and dynamic cards.
* **JavaScript (ES6+)** – Dynamic logic and data management.

## Key Implementations:
* **localStorage** – For client-side data persistence.
* **Full CRUD** – Create, Read, Update, and Delete functionality for habit management.
* **Event Listeners** – Handling user interactions.
* **Dynamic Timers** – Unique timers for each habit card.
* **Real-time Filtering** – Filtering lists based on user input.

## Features Summary

## My Habit (Core Feature)
* Add new habits.
* Edit existing habits.
* Delete habits.
* Filter by category or status.
* Set a unique timer for each habit.
* Automatic saving to `localStorage`.
